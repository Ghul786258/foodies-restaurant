FOODIES RESTAURANT — FRONT-END PORTFOLIO DEMO

FILES
- index.html: page structure and sections
- style.css: responsive styling
- script.js: sample menu, category filters, search, cart, quantity controls, totals, and localStorage

HOW TO RUN
1. Extract the ZIP file.
2. Open the foodies-restaurant folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Add food to the cart and refresh the page to test localStorage persistence.

NOTES
- This is a front-end demo. Checkout and contact form do not submit to a server.
- Menu prices and contact details are fictional sample data.
- Food photos load from Unsplash over the internet, so an internet connection is needed for those images.
- Replace sample text, prices, photos, address, and phone number before presenting it as a real restaurant site.
- Real ordering, payments, user accounts, admin tools, and database storage require backend/service integration.
